> A lightweight, blazing-fast Thunderbird extension designed to quickly mark all messages across folders and accounts as **read** with a single click
---

## ✨ Features

- ⚡ **One-Click Mark All as Read:** Instantly clear unread badges across selected folders, entire accounts, or all subfolders.
- ⌨️ **Customizable Keyboard Shortcuts:** Trigger the command instantly without touching your mouse.
- 🎨 **Seamless Integration:** Designed to match Thunderbird's native theme (supports both Light and Dark modes).
- 🔒 **Privacy First:** Zero telemetry, no external network requests, and open-source.

---

## 🚀 Quick Start

### Installation

1. Download the latest release (`.xpi` file) from the [Releases page](../../releases).
2. Open **Thunderbird**.
3. Go to **Tools** > **Add-ons and Themes** (or press `Ctrl+Shift+A` / `Cmd+Shift+A`).
4. Click the gear icon ⚙️ in the top right corner and select **Install Add-on From File...**.
5. Select the downloaded `.xpi` file and click **Add**.
